## 基础后端写法调整

Flask 实例改为在根目录直接创建，权限检查改为路由调用普通函数并使用 if 判断。库存扣减、归还、人工调整及订单状态变化改为参数化 text SQL，不再使用应用工厂、自定义权限装饰器或显式行锁 API。

保持表结构、页面和接口地址不变，保留事务回滚、金额快照、订单归属检查和重复操作保护。调整后 24 项完整测试全部通过，数据库模型与迁移检查一致。MySQL 实际运行仍待验证。
