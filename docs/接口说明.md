# 序仓接口说明

接口统一使用 `/api` 前缀，返回 UTF-8 JSON。浏览器页面与接口同源，登录使用 Session Cookie。

成功响应示例：

```json
{"data": {"id": 1}, "csrf_token": "页面凭证"}
```

失败响应示例：

```json
{"error": {"message": "请先登录"}, "csrf_token": "页面凭证"}
```

写请求必须先调用 `GET /api/auth/session` 获取 `csrf_token`，然后在请求头传入 `X-CSRF-Token`。同时保留返回的 Session Cookie。每次响应中的新凭证应保存，尤其在注册、登录和退出后。使用页面时，这些操作已由前端自动完成。

## 接口清单

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| GET | /api/auth/session | 无需登录 | 当前用户与页面凭证 |
| POST | /api/auth/register | 无需登录 | 注册普通用户并登录 |
| POST | /api/auth/login | 无需登录 | 登录 |
| POST | /api/auth/logout | 已登录 | 退出 |
| GET | /api/products | 已登录 | 商品分页、搜索、状态筛选 |
| POST | /api/products | 管理员 | 新建商品 |
| PATCH | /api/products/{id} | 管理员 | 修改名称、描述、价格、上下架 |
| POST | /api/products/{id}/stock | 管理员 | 人工增减库存 |
| GET | /api/stock-movements | 管理员 | 库存流水 |
| POST | /api/orders | 已登录 | 创建自己的订单 |
| GET | /api/orders | 已登录 | 查看可访问的订单 |
| GET | /api/orders/{id} | 订单所属用户或管理员 | 查看订单明细 |
| POST | /api/orders/{id}/cancel | 订单所属用户或管理员 | 取消待付款订单 |
| POST | /api/orders/{id}/pay | 订单所属用户或管理员 | 模拟付款 |
| POST | /api/orders/{id}/ship | 管理员 | 将已付款订单发货 |
| POST | /api/orders/{id}/complete | 订单所属用户或管理员 | 将已发货订单确认收货 |
| GET | /api/dashboard | 已登录 | 订单统计；管理员另有库存提醒 |

状态码：创建成功 `201`，正常查询或修改 `200`，参数错误 `400`，未登录 `401`，角色或页面凭证不允许 `403`，资源不存在或订单无访问权限 `404`，唯一值冲突、库存不足或状态冲突 `409`，数据库错误且已回滚 `500`。

## 请求示例

注册及登录：

```json
{"username":"wangxiu", "password":"自设的至少八位密码"}
```

创建商品：

```json
{"sku":"BOOK-001", "name":"后端学习笔记", "description":"练习商品", "price":"29.90", "stock":20}
```

修改商品：

```json
{"price":"32.00", "is_active":true}
```

库存调整：

```json
{"delta":5, "note":"采购补货"}
```

负数表示减少库存。`delta` 不能为零，调整原因不能为空，调整后的库存不能为负。

创建订单：

```json
{
  "request_key":"client_request_0001",
  "items":[{"product_id":1,"quantity":2},{"product_id":2,"quantity":1}],
  "note":"第一次订单练习"
}
```

`request_key` 由客户端为一次提交生成。网络中断后重试同一请求应复用它，修改订单内容则需使用新的编号。重复提交已成功创建的请求返回同一订单，状态码为 `200`。不接受商品价格、总价、用户编号或订单状态等额外字段。

取消、付款、发货、收货请求体均为 `{}`。

## 查询参数

分页通用参数：`page=1&page_size=12`。页码为 1 至 100000，每页条数为 1 至 100。

- 商品：`q` 搜索名称或 SKU，`active=1` 已上架、`active=0` 已下架。普通用户始终只能看到已上架商品。
- 订单：`q` 搜索订单号，`status` 支持 `pending/paid/shipped/completed/cancelled`。
- 订单日期：`from=2026-10-12&to=2026-10-15`，包含两个 UTC 日历日期。
- 库存流水：`product_id=1` 按商品筛选。

分页响应中的 `data` 包含 `items`、`total`、`page`、`page_size` 和 `pages`。金额返回字符串，避免 JSON 浮点数导致金额精度损失。
